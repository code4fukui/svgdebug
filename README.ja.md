# svgdebug
[README.ja.md](README.ja.md)に日本語の説明があります。

シンプルなSVG描画ツールです。

## デモ
https://code4fukui.github.io/svgdebug/

## 機能
- クリックしてラインを描く
- コマンド/Altクリックで図面を移動する
- Ctrl+Zで図面を元に戻す
- SVG図面をダウンロードする

## 使い方
このツールはWebブラウザから利用できます。グリッド上をクリックまたはコマンド/オルトクリックすることで、線やシェイプを描くことができます。生成されたSVGコードはテキストエリアに表示され、「SVGのダウンロード」ボタンをクリックすることでダウンロードできます。
